## 开发人
在这个Blog项目中，Sonetto Sakuraba将会是全权开发人。您可以下载这个项目并修改为您的项目，您对您的项目拥有所有权。

## 用法
请访问[Pages 页面](SonettoSakuraba.github.io/Blog "点击访问Sonetto Sakuraba的Blog的Github Pages页面")以获得用户的体验。
如果您不是指本Blog的用法而是本项目内容的用法：
  1.下载本项目，
  2.删除index.html、icon.ico里面有关于Sonetto的任何信息，
  3.通过editor.py（往后简称编辑器）删除现有的文章，
  4.将您自己的信息或内容（如果您希望）填写进index.html、icon.ico，并且通过editor.py将您自己的文章刊登入text.py，
  5.根据您自己的审美修改Style.css（记得是大写首字母）
